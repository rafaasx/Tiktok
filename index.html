ASR Publisher

Personal desktop tool that publishes my own videos to my own social media accounts (TikTok, Instagram, YouTube) through each platform's official API.

ASR Publisher is a private, single-user automation. It is not a public service: it only uploads content created by the operator to the operator's own connected accounts, within the scopes granted by each platform.
